# ⚡ Nexus UI Library

A modern, high-performance dark-themed UI library for Roblox script development. Styled after clean modular cheat panels with crimson accents, built-in layout management, auto-saving configuration support, and smooth animated controls.

---

## 📸 Overview

* **Accent Theme:** Dark Crimson Red (`RGB: 220, 35, 35`)
* **Default Toggle Key:** `RightShift`
* **Configuration File:** `NexusUI_Config.json` (auto-saves toggle states)

---

## ⚡ Quick Start / Script Loader

Add this loadstring to the top of your script to fetch the library directly from GitHub:

```lua
local Library = loadstring(game:HttpGet("[https://raw.githubusercontent.com/minecraftpe012/Nexus-UI-Libary/refs/heads/main/src.lua](https://raw.githubusercontent.com/minecraftpe012/Nexus-UI-Libary/refs/heads/main/src.lua)"))()
